# k-osint
> ### is a fast, automated Open Source Intelligence (OSINT) toolkit designed to streamline reconnaissance and digital investigations for security researchers and analysts.


 * **Automated & Rapid Intelligence**: Speeds up passive information gathering by automating time-consuming queries across web assets, subdomains, and infrastructure.
  
 * **Streamlined Web Interface**: Includes a dedicated GitHub Pages portal (.github.io) that eliminates manual query syntax by offering clean, quick-filter search interfaces.
  
 * **Google Dork Engine**: Simplifies advanced Google searching with categorized, one-click dork templates to uncover exposed files, directories, and web vulnerabilities.
  
 * **Shodan Search Filters**: Built-in Shodan filters make it effortless to discover connected IoT devices, open ports, vulnerable software versions, and specific network ranges.
